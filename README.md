# ТВ Кнопки

Переназначение кнопок ИК и Bluetooth пультов для Android TV. Рабочий режим ADB проверен на Яндекс ТВ YNDX-00092, Android 11.

## Два режима в версии 0.3.0

* **Через ADB**: встроенный клиент подключается только к 127.0.0.1:5555 и запускает помощника от обычного ADB shell, без root. На ТВ должна быть включена отладка ADB по сети. Постоянное подключение к компьютеру не требуется.
* **Без ADB**: пользователь включает службу «ТВ Кнопки» в специальных возможностях Android. Приложение использует стандартные API для клавиш, громкости, медиакоманд, запуска приложений, мыши и экранных действий. В этом режиме служба ADB останавливается.

Выбор режима находится на главном экране. Назначения общие для обоих режимов; одно нажатие обрабатывает только выбранный обработчик. Существующие установки сохраняют режим ADB, новые начинают с режима без ADB.

**0.3.0 — тестовый релиз.** На проверенной прошивке Яндекс ТВ не удалось включить стороннюю службу: после попытки добавить её список включённых служб возвращался к двум службам Яндекса. Поэтому полноценная проверка режима без ADB на этом ТВ не состоялась. Не следует считать его проверенным на других телевизорах. Тестовый эмулятор на компьютере также не удалось запустить.

## Установка

Скачайте APK из Releases и установите обычным способом или через ADB. Для режима без ADB откройте «Режим: без ADB» → «Включить службу / специальные возможности» и подтвердите включение «ТВ Кнопки» в настройках Android. Если прошивка скрывает или блокирует сторонние службы, этот режим включить не получится.

В режиме ADB для курсора, часов и чёрного экрана требуется разрешение отображения поверх приложений; при запросе подключения ADB подтвердите его на телевизоре. Автозапуск зависит от разрешений и ограничений прошивки.

## Действия

Обычное, двойное и долгое нажатие настраиваются отдельно. Доступны запуск приложения, Домой, Назад, недавние приложения, громкость и отключение звука, воспроизведение/пауза, перемотка, предыдущий/следующий трек, настройки и голосовой помощник. Есть мышь со стрелками, кликом по OK и выходом через Назад, прокрутка и возврат к предыдущему приложению.

Продвинутые действия: скриншоты, таймер сна, чёрный экран со звуком, часы поверх изображения, HTTP/HTTPS ссылки и макросы с задержками.

Без ADB принудительное закрытие/перезапуск чужих приложений и переключение каналов недоступны. HDMI на проверенной прошивке Яндекс ТВ защищён системным разрешением и требует режима ADB. Недоступные действия помечены в интерфейсе. Медиакоманды и жесты зависят от поддержки приложением; не все физические кнопки прошивка передаёт службе.

Физическая кнопка питания сохраняет штатное поведение. Без ADB назначение питания переводит экран в сон через API Android 9+, оно не гарантирует пробуждение. Без ADB скриншоты требуют Android 11+. Чёрный экран перекрывает изображение, но не выключает подсветку. Таймер действует, пока работает обработчик; смена режима отменяет его.

Служба специальных возможностей получает элементы экрана для мыши, прокрутки и выбора входа; скриншот делает только по назначенной команде. Содержимое экрана не отправляется в сеть. В режиме ADB служба специальных возможностей не перехватывает клавиши и не запрашивает события окон.

## Проверки

Сборка приложения и отдельного тестового APK прошла. Автотесты логики нажатий прошли: обычное, отложенное обычное, двойное, долгое, удержание второго нажатия, повторные события, одновременные клавиши, отмена при переключении и ограничения API.

На ТВ проверены тесты помощника ADB, переключение режима с остановкой службы ADB и возврат обратно с сохранением назначений. Полные инструментальные тесты без ADB подготовлены, но не выполнены: включение службы на ТВ заблокировано, эмулятор не запустился.

## Сборка

JDK 17, Android SDK 35. Создайте local.properties с sdk.dir для своего SDK. Команды: `gradlew.bat assembleDebug` и `gradlew.bat assembleDebugAndroidTest` (Windows), либо `./gradlew` на Linux/macOS.

Тест логики клавиш: скомпилируйте KeyPresses.java, ActionSupport.java и tools/tests/KeyPressesTest.java, затем запустите org.tvbuttons.free.KeyPressesTest. Инструментальные тесты находятся в app/src/androidTest и требуют включённой службы на тестовом Android-устройстве.

Опубликованный APK подписан существующим ключом разработческой сборки. Самостоятельная сборка другим ключом не обновляет этот APK поверх установленного.
