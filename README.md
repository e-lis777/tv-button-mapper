# ТВ Кнопки

Переназначение кнопок ИК и Bluetooth пультов для Android TV. Экспериментальная версия, проверенная на Яндекс ТВ YNDX-00092 с Android 11.

## Установка

Скачайте APK из [релиза 0.2.0](https://github.com/e-lis777/tv-button-mapper/releases/tag/v0.2.0) и установите на ТВ. Приложению нужна включённая отладка ADB по сети. Встроенный клиент подключается только к 127.0.0.1:5555 и запускает помощника от обычного ADB shell, без root. Если система запрашивает разрешение подключения ADB, подтвердите его на ТВ.

Для часов, курсора и чёрного экрана требуется разрешение отображения поверх других приложений. Автозапуск после загрузки зависит от разрешений и ограничений прошивки телевизора.

## Действия

Питание, Домой, Назад, настройки, HDMI, громкость и отключение звука, воспроизведение/пауза, перемотка, треки и каналы, вызов Алисы на Яндекс ТВ. Управление приложениями: запуск, предыдущее приложение, закрытие и перезапуск пользовательского приложения. Мышь с пульта, прокрутка, настройки Wi-Fi, подключение Bluetooth.

Продвинутые действия: скриншоты в Pictures/TVButtons, таймер сна, чёрный экран со звуком, часы, HTTP/HTTPS ссылки и макросы с задержками. Чёрный экран — программное перекрытие изображения, он не выключает подсветку матрицы. Таймер действует пока работает служба.

Обычное, двойное и долгое нажатие настраиваются отдельно. Названия приложений отображаются рядом с назначениями. Физическая кнопка питания сохраняет штатное поведение. Пробуждение назначенной кнопкой зависит от работы Android и приёма пульта в режиме ожидания. Медиакоманды зависят от поддержки проигрывателем.

Проверены сборка, обработка обычного/двойного/долгого нажатия, сохранение скриншота и самостоятельное восстановление помощника. Все действия во всех проигрывателях пока не проверены. HDMI и часть настроек реализованы с учётом прошивки данного Яндекс ТВ.

## Сборка

JDK 17, Android SDK 35. Создайте local.properties с sdk.dir для своего SDK и выполните `gradlew.bat assembleDebug` (Windows) или `./gradlew assembleDebug`.

APK релиза подписан существующим ключом разработческой сборки. Самостоятельная сборка с другим ключом не устанавливается как обновление поверх опубликованного APK.
